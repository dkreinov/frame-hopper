# Current creator-site offers (reviewed 2026-10-02)

This is a **discovery catalog**, not a credit balance or a promise that a model is enabled in a particular account. `confirmed` means an official current page describes free use of that model family; `conditional` means an event, welcome grant, or model restriction must be checked; `unverified` means the site lists the model but its free-plan access is not established; `paid` means the current plan page places it behind a paid tier. Refresh the official sources and the live signed-in form before spending any credits.
